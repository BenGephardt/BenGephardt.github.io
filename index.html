Accessible Virtual Keyboard

Responsive Accessible Virtual Keyboard

A fully responsive, WCAG-compliant virtual keyboard built with CSS Grid and event-driven JavaScript.

Problem
On-screen keyboards are often inaccessible, hard to navigate via keyboard, and difficult to use on smaller devices.
Tech stack
CSS Grid layout, ARIA attributes, vanilla JS event delegation.
Solution
Implemented a grid-based key layout with clear focus states, logical navigation order, and efficient event delegation for responsive, low-latency input.
