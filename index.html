About

Hi, I'm Benjamin Gephardt, a front-end web developer based in Manitou Springs, Colorado.

I craft accessible, responsive interfaces where every interaction feels intentional. A background in Behavioral Therapy and a BFA in Illustration gives me a trained eye for inclusive design and a visual precision that shows in the code.

I focus on thoughtful details, robust semantics, and real-world performance that holds up beyond a case-study screenshot. I thrive collaborating with teams to turn complex requirements into resilient, WCAG-compliant UI patterns.

When I'm offline, you'll find me reimagining historical recipes in the kitchen, assembling a Charles Wysocki puzzle, or deep in planning for my latest Dungeons & Dragons campaign.

Wandering Arcanum

Wandering Arcanum App

An interactive 5e web application that turns complex rules and spell options into an intuitive, story-friendly interface.

Problem
Players wasted valuable session time digging through rulebooks or navigating bloated, ad-heavy third-party tools with poor UX.
Tech stack
React 18, React Router, Vite, modern CSS, accessible UI components.
Solution
Built a searchable, filterable multi-page app with seamless client-side routing, semantic heading structure, and full ARIA-compliant keyboard navigation to deliver a clean, distraction-free experience players can rely on at the table.

Alpine Autism Center

Alpine Autism Center Website

A real-world client website for a local autism center, focused on clarity, trust, and accessible information architecture.

Problem
The center lacked a modern web presence; staff couldn't update content without developer help, and the existing site failed to clearly communicate services to families seeking support.
Tech stack
Squarespace (CMS), Custom CSS, Vanilla JavaScript, Information Architecture.
Solution
Designed an information-first layout with WCAG-compliant contrast, clear navigation, and structured content before handing off a CMS-backed site the team could manage and update entirely on their own.

Gridboard

GridBoard

A fully responsive, WCAG-compliant virtual keyboard built with CSS Grid and event-driven JavaScript.

Problem
Most on-screen keyboards fail basic accessibility standards, being hard to navigate without a mouse, lacking visible focus states, and breaking down on small screens.
Tech stack
CSS Grid layout, ARIA attributes, vanilla JS event delegation.
Solution
Implemented a grid-based key layout with high-visibility focus states, logical tab order, and efficient event delegation to produce a responsive, low-latency keyboard usable entirely without a mouse.
