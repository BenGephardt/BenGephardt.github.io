About

Hi, I'm Benjamin Gephardt, a front-end web developer based in Manitou Springs, Colorado.

I craft accessible, responsive interfaces that feel effortless to use. By leveraging a unique background in Behavioral Therapy and a BFA in Illustration, I bring a rare blend of deep empathy and visual precision to my code.

I focus on thoughtful details, robust semantics, and real-world performance that holds up beyond a case-study screenshot. I enjoy collaborating with teams to turn complex requirements into resilient, WCAG-compliant UI patterns.

When I am offline, you can usually find me reimagining historical recipes in the kitchen, assembling a Charles Wysocki puzzle, or planning my latest Dungeons & Dragons campaign.

Gridboard

Gridboard

A fully responsive, WCAG-compliant virtual keyboard built with CSS Grid and event-driven JavaScript.

Problem
On-screen keyboards are often inaccessible, hard to navigate via keyboard, and difficult to use on smaller devices.
Tech stack
CSS Grid layout, ARIA attributes, vanilla JS event delegation.
Solution
Implemented a grid-based key layout with clear focus states, logical navigation order, and efficient event delegation for responsive, low-latency input.
